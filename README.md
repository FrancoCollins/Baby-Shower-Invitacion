# Baby Shower · Franco & Agustina — edición acuarela

Invitación digital estática, diseñada para funcionar al abrir `index.html` o publicarse directamente en GitHub Pages. Está hecha con HTML, CSS y JavaScript nativos; no requiere instalación, compilación, backend ni variables de entorno.

## Vista local

Abre `index.html` en un navegador. Las ilustraciones originales de ositos en acuarela están guardadas en `assets/images/`. Las tipografías se cargan desde Google Fonts; el sitio mantiene tipografías de sistema como alternativa si no hay conexión.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a la rama principal de un repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, la rama principal y la carpeta `/ (root)`.
4. Guarda y abre la URL que GitHub Pages muestra en esa sección.

No hay que ejecutar comandos de build. Las rutas a CSS, JavaScript e ilustraciones son relativas, por lo que funcionan en la raíz del sitio y dentro de la ruta de un repositorio.
